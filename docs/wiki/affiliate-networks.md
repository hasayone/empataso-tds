# Партнёрские сети

`GET|POST /api/affiliate-networks` и `GET|PUT|DELETE /api/affiliate-networks/{id}`.

Поля: `id`, `name`, `status`, `postback_url`, `offer_param`, `offer_query`, `group`.

Подпись группы — поле `group` в `networks.json`. Поиск на странице сети идёт по номеру, имени, группе, `postback_url` и `offer_query`. Общие правила групп, фильтров и окна «Группы» — в [офферах и лендингах](offers-landings.md), раздел «Группы и поиск».

Номер выдаёт сервер, если в `POST` нет `id`. Id сети — числовой. Файл `network_seq.json` только растёт, удалённый номер не возвращается. Явный `id` принимается. Форма его не отправляет. Правка идёт через `PUT` и сохраняет `offer_param` и `status`.

Таблица сортируется щелчком по заголовку любого включённого столбца: №, имя, группа, клики, лиды, продажи, отклонённые, CR, EPC, CPC, доход, депозит, расход, прибыль, ROI. «Группа» включена по умолчанию. Повторный щелчок меняет направление. Первый щелчок по числовому столбцу идёт по убыванию, по имени — по возрастанию. uEPC, CR подтв. и CR режима сортируются так же, когда шестерёнка их включает. Сортировка и набор столбцов хранятся в `/api/me/views`.

Внизу `#/networks` закреплён тот же двухрядный блок, что у кампаний: верхний ряд — суммы отфильтрованного списка (клики, уники, конверсии, продажи, расход, доход, депозит, прибыль, ROI, EPC; проценты не складываются, депозит не входит в доход), нижний — страница, размер (10/25/50/100/1000 или своё до 5000, по умолчанию 50) и экспорт CSV/HTML всех строк фильтра, не страницы. Скрытый `profit` прячет деньги в футере. Поиск, группа и сортировка возвращают на первую страницу. Размер страницы хранится в `networks.page` у `/api/me/views`, не в `localStorage`. Вложенная таблица офферов открытой сети не пагинируется и второго блока не получает.

`postback_url` — заметка для кабинета сети. Движок её не вызывает и вторую очередь не поднимает.

`offer_query` — строка вроде `sub1={subid}`. Она дописывается к ссылке, которую видит посетитель, после того как оффер уже узнан по адресу без этой склейки. Уже стоящий query не затирается. Адрес длиннее 500 символов, с пробелом или со схемой `://` даёт `400`. Шаблон `clickid, goal, sum` не подставляет `offer_id` в `offer_query`.

Строка сети на странице — сумма кликов и конверсий с этим `network_id` за период. Доход подтверждённый считает статусы `lead` и `sale`. Открытие строки показывает офферы этой сети.

Шаблон по умолчанию: `{engine}/postback?subid={subid}&status={status}&payout={payout}`. Готовые адреса копируются из меню пользователя, пункт «Постбеки» выше настроек: лид без выплаты, продажа с `payout={payout}`, «Копировать все» кладёт обе строки. Поле сети `postback_url` остаётся заметкой и движок его не вызывает.

Шестерёнка столбцов сети помнит порядок в `kuztds-net-cols`. Деньги в таблице — `moneyText` с двумя знаками и группировкой разрядов; пустой код расхода — USD (`0.00 $`), с другой валютой — код (`0.00 EUR`). Столбец «Уники» (`uniq`) в сетях выключен по умолчанию и считает `uniq` строк сети. Доход без расхода даёт ROI `100%` только когда у кампании за период нет расхода. Неразложенный расход кампании этот процент сети не ставит. Несколько валют в один процент не склеиваются.

У оффера поле `network_id`. Закрытый каталог шаблонов сетей не скачивается и на сервер не пишется.
