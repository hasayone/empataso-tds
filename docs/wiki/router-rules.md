# Правила потока

Обычный поток по-прежнему берёт первое совпадение, где прошли все условия.

- `filter_or: true` — достаточно одного настроенного условия. Лимит показов остаётся обязательным.
- `weight: true` у группы — среди подходящих потоков выбор по полю `weight` потока, а не всегда первый.
- Несколько офферов — выбор URL по `share`.
- Если у потока есть и лендинг, и оффер, первый ответ — лендинг. Оффер открывается по пути `/<поток>/offer`.

`POST /api/simulate` возвращает выбранный URL. Поле `roll` фиксирует жребий в тесте.
