# Правила потока

Обычный поток берёт первое совпадение, где прошли все условия.

- `filter_or: true` — достаточно одного настроенного условия. В редакторе это пункт «любое из этих условий»; «все эти условия» оставляет флаг выключенным. На схеме между условиями стоит «или». Лимит показов остаётся обязательным и проверяется последним.
- `weight: true` у группы — среди подходящих потоков выбор по полю `weight` потока, а не всегда первый.
- Несколько офферов — выбор URL по `share`.
- Если у потока есть и лендинг, и оффер, первый ответ — лендинг. Оффер открывается по пути `/<поток>/offer`.

`proxy` и `ip_version` устроены как `unique` и `bot`: `0` — выключено.

- `proxy`: `1` (флаг A) — только прокси, `2` (флаг B) — только не прокси.
- `ip_version`: `1` (флаг A) — только IPv4, `2` (флаг B) — только IPv6. IPv4 включает IPv4-mapped: адрес `::ffff:1.2.3.4` проходит `1` и не проходит `2`. Невалидный адрес не проходит ни `1`, ни `2`.

В режиме `filter_or` `proxy` и `ip_version` — отдельные условия. Хватает одного. Лимит показов после них всё равно обязателен.

Прокси считается локально, на клике внешние API не вызываются. Адрес есть в списке `ip_proxy.dat`, либо название организации сети из базы ASN содержит подстроку из `proxy_org.dat`. Сравнение без учёта регистра. Пустое имя и «-» прокси не дают. Встроенный список — `internal/detect/proxy_org.dat`. Файл `proxy_org.dat` в каталоге данных его заменяет. Его правят в «Списках»: `GET` и `PUT /api/lists/proxy_org.dat`. Откуда берётся `ip_proxy` — в [защите от ботов](bot-protection.md).

Признак для правила `bot` ставит профиль установки до выбора потока. Блок «Боты» у потока на этот признак не влияет: он пишет метку в журнал и может отдать боту отдельный ответ. Подробнее — [Защита от ботов](bot-protection.md).

У типа устройства флаг `1` блокирует этот тип. Чтобы условие типа прошло у компьютера, ставят `phone: 1` и `tablet: 1`. Телефон и планшет тогда условию не проходят.

`POST /api/simulate` возвращает выбранный URL. Поле `roll` фиксирует жребий в тесте. Симулятор гоняет правила потока и не запускает детекцию ботов.
