# Фильтры и столбцы журналов

Кнопка «Фильтры» открывает один конструктор. Он есть у журнала кликов, журнала конверсий, отчёта `#/report` и у блока «Кто заходит» на сводке. Клики, отчёт и сводка фильтруют таблицу `events`. Конверсии фильтруют `conversions`. Набор условий показывает счётчик на кнопке и чипы под ней. Снятие чипа убирает одно условие. «Сбросить фильтры» очищает черновик. «Применить» оставляет строки, у которых выбрано поле и хотя бы одно значение.

## Конструктор

В одной форме каждое поле можно выбрать только в одной строке: занятые поля не предлагаются в других строках. «Добавить фильтр» неактивна, когда свободных полей не осталось. При «Применить» повторы одного поля схлопываются до первой строки (`dedupeConds`). Несколько значений одного поля задают оператор «Из списка» (`in`): Enter или запятая добавляют значение в список.

Подсказки значений для поля «Устройство» показывают фразу и код, например «Мобильный телефон · phone». Операторы и поля — ниже.

Поля в списке собраны в группы: Данные, Гео, Устройство, Источник, Sub ID. В списке только поля, у которых на этой таблице есть столбец и готова волна. Подсказки значений идут из `GET /api/log-values` и только у измерения: период шапки, таблица и поле. Поле без измерения подсказок не получает, значение вводится вручную. У оффера, лендинга, сети, источника и id кампании рядом с id показывается имя из каталога.

Sub ID 1…12, сайт, Ad Campaign ID, Creative ID и External ID — измерения. Конструктор подсказывает их значения, `GET /api/stats/breakdown?dim=` их принимает. Карточка «Своё измерение» по умолчанию стоит на Sub ID 1, когда волна `click` готова.

## Операторы

| Оператор | Подпись | Смысл |
| --- | --- | --- |
| `eq` | Равно | значение входит в список |
| `ne` | Не равно | значения нет в списке, и само поле не пустое |
| `in` | Из списка | то же сравнение, что у «равно», несколько значений |
| `nin` | Исключение списка | то же, что у «не равно», несколько значений |

«Равно» и «не равно» в конструкторе держат одно значение. «Из списка» и «исключение списка» копят несколько: Enter или запятая добавляют значение. Пустая строка из поля ввода не уходит.

«Не равно» и «исключение списка» добавляют к сравнению требование, что значение столбца не пустая строка. Строка с пустым городом не попадает в выборку «город не равно Warsaw». Ноль ASN в измерении тоже считается пустым: в сравнении он выглядит как пустая строка, а не как `AS0`.

У статуса перед сравнением значение обрезается по краям и приводится к нижнему регистру. Остальные поля сравниваются как введены.

## Формат `f=`

Повторяемый параметр `f=field:op:value`. Двоеточие делит строку на три части, значение может содержать свои двоеточия. Одинаковые поле и оператор склеиваются в одно условие, в порядке первого появления. Несколько `eq` одного поля становятся `in`, несколько `ne` — `nin`. Пустое значение после второго двоеточия сохраняется.

Незнакомое поле, поле без столбца на этой таблице, оператор вне четырёх, пустой список значений, больше 20 условий или больше 200 значений в одном условии дают `400` и текст `bad filter:`.

Фильтр по полю, чья волна на таблице ещё не готова, не отвечает ошибкой: журнал отдаёт пустую страницу и запрос не выполняет. Сводка и список значений в этом случае отдают пустой список и `200`.

`GET /api/log-fields` отдаёт каталог полей и готовность волн `ready`. Без статистики каталог всё равно `200`, а `ready` пустой. `GET /api/log-values` принимает `table` (`events` или `conversions`), `field`, `from`, `to` и `limit`. `limit` не больше 500, пустой или больший становится 500. Поле без измерения — `400`. Неготовая волна — `200` и пустой список.

Старое имя измерения `group` сервер читает как `campaign`.

## Лимиты страниц

Журнал кликов `GET /api/logs`: `limit` по умолчанию 100, потолок 1000, `offset` ниже нуля становится нулём. CSV `GET /api/logs/export` берёт те же фильтры, `offset` 0 и не больше 50 000 строк. Ячейка, которая начинается с `=`, `+`, `-`, `@` или перевода строки, получает ведущий апостроф.

Журнал конверсий `GET /api/postbacks`: вместе со старыми параметрами принимает `f=` и `offset`. В интерфейсе страница — 200 строк. Полная страница показывает «Показать ещё» и запрашивает следующие 200. У API `limit` выше 1000 возвращается к 200.

`GET /api/report` принимает `f=` по кликам. Кнопка на `#/report` сохраняет полученный срез в CSV. `GET /api/stats/breakdown` принимает `dim`, `limit` и `f=` по кликам. `limit` пустой или выше 1000 становится 50. Сводка запрашивает шесть значений. Измерение вне каталога или поле без измерения — `400`. Неготовая волна измерения — пустой список и `200`.

`GET /api/stats/summary`, `GET /api/stats/timeseries`, `GET /api/stats/performance` и `GET /api/stats/facts` принимают `from`, `to` и те же `f=` по кликам. У ряда timeseries параметр `step` в секундах, не меньше 3600.

## Столбцы по умолчанию

Шестерёнка есть у журнала кликов, журнала конверсий и отчёта. Порядок и включение хранятся на сервере в `ui.json` (`cols`, ключи `logs`, `conv`, `report` и др.) через `GET`/`PUT /api/ui`. При первом входе админка может перенести старый набор из `localStorage` в файл и сохранить на сервер. Сброс возвращает набор ниже. Пока хотя бы один столбец включён, последний включённый снять нельзя.

Клики, включены: время клика, кампания, поток, страна, устройство, OS / browser, бренд, Visit, IP, ключевик, вывод.

Клики, выключены: город, регион, язык, оператор, тип, реферер, User-Agent, домен, subid, ASN, провайдер, часовой пояс, Sub ID 1…12, оффер, лендинг, партнёрская сеть, источник, числовые id оффера, лендинга, сети и источника, id кампании, сайт, X-Requested-With, Ad Campaign ID, Creative ID, External ID, обе маски IP, версия ОС, версия браузера, поисковик, уникальность, Via, страница.

Конверсии, включены: subid, Sub ID 1, Sub ID 2, кампания, поток, оффер, партнёрская сеть, страна, доход, статус, время конверсии, период продажи, оригинальный статус, город, регион.

Конверсии, выключены: группа кампании, лендинг, источник, сайт, X-Requested-With, реферер, поисковик, ключевик, id кампании, числовые id каталога, Ad Campaign ID, External ID, Creative ID, Sub ID 3…12, оператор, провайдер, язык, устройство, User-Agent, ОС и версия, браузер и версия, бренд, IP и обе маски, время клика, предыдущий статус, TID, домен, страница.

Отчёт, включены: кампания, поток, страна, оффер, источник, визиты, боты, конверсии, прибыль. CR выключен.

## Вычисляемые столбцы

Их нет в каталоге `GET /api/log-fields`. Значение считается в браузере из уже пришедшей строки.

Период продажи — разница между временем конверсии и временем клика. Нет времени клика или нечитаемой даты — пусто. Отрицательная разница показывается как ноль. От суток — дни и часы, иначе часы и минуты, иначе минуты, иначе секунды. Столбец виден, когда готовы и время конверсии, и `click_ts`.

IP 1.2.*.* оставляет два первых октета IPv4, IP 1.2.3.* — три. Адрес не из четырёх десятичных октетов даёт пустую ячейку. Оба столбца выключены и зависят от поля `ip`.

OS / browser на кликах склеивает ОС и браузер. Visit показывает бота, уникальный визит или повтор. Группа кампании — папка кампании из каталога, не столбец журнала. Столбцы «ID оффера», «ID лендинга», «ID сети» и «ID источника» показывают числовой id. Соседние столбцы с теми же полями показывают имя из каталога.

ASN в ячейке и в измерении пишется с приставкой `AS`. Ноль остаётся пустым.

Подпись — русская подпись интерфейса. «Клики» и «конверсии» — есть ли столбец в `events` и `conversions`. «Измерение» — поле можно выбрать в `dim` сводки и получить подсказки `GET /api/log-values`. Фильтровать можно и поле без измерения.

## Срок хранения копий

Таблица `events` удаляет строку через 21 день после `ts`: `TTL ts + INTERVAL 21 DAY` в `migrations/clickhouse/001_events.sql`. Таблица `conversions` удаляет строку через 365 дней после `ts`: `TTL ts + INTERVAL 365 DAY` в `migrations/clickhouse/004_conversion_status.sql`. Поздние миграции этот TTL не меняют. Столбцы `ip`, `useragent` и `referer` в `conversions` — обычные колонки той же таблицы, своего TTL у них нет. Копия живёт столько же, сколько строка конверсии: 365 дней от времени постбека. Срок клика в `events` на эту копию не влияет.
