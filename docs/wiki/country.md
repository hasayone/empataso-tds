# Страна

Страница `#/settings`, третья карточка.

- Язык имён: `en`, `ru`, `uk`. Хранится в браузере (`kuztds-lang`) и ставится в `html lang`.
- Поиск идёт сразу по коду, английскому, русскому и украинскому имени, независимо от выбранного языка.
- В чипе условия — флаг и имя. Двухбуквенный код только в подсказке. В сохранённый поток уходит код.
- Источник страны по умолчанию для нового потока: заголовок CDN (`cf`) или гео-база (`db`), ключ `kuztds-geo-default`. Уже сохранённый поток это поле не переписывает.

Справочник вшит в страницу админки. Сервер стран не отдаёт отдельным файлом.
