# Страна

Страница `#/settings`, третья карточка.

- Язык имён: `en`, `ru`, `uk`. Хранится в браузере (`emtds-lang`) и ставится в `html lang`.
- Поиск идёт сразу по коду, английскому, русскому и украинскому имени, независимо от выбранного языка.
- В чипе условия — флаг и имя. Двухбуквенный код только в подсказке. В сохранённый поток уходит код. Флаги во всём интерфейсе — `<img>` из встроенного набора flag-icons 7.6.0 (`flags/4x3`, коды ISO alpha-2), URL `/assets/flags/{cc}.svg`; неизвестный код при ошибке загрузки скрывает картинку, имя остаётся.
- Источник страны по умолчанию для нового потока: заголовок CDN (`cf`) или гео-база (`db`), ключ `emtds-geo-default`. Уже сохранённый поток это поле не переписывает.

Справочник вшит в страницу админки. Сервер стран не отдаёт отдельным файлом.
